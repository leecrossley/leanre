## 3. Quantitative Exponents & `Real.rpow` Error Cancellation `[L]` `[S]`

All asymptotic budgets are driven by `ε < 1/52` ([Scale.eps_lt](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/LocalRingCardinality/DataParams₂.lean#L14)), `delta1 = x^(-ε/8)`, `L = x^ε`, `b = exp(x^ε)`, `a = x * b`, `X' = exp(x^(ε/3))`, and window constraints ([ElevenLe](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/SharpRestriction/ElevenLe.lean#L24)): `n ∈ x^(2 + 8ε ± ε/100)`, `m ∈ x^(±ε/100) * √(x * delta1)` (`m ≈ x^(1/2 - ε/16)`, with `x*m <= k` and `m <= x^(1/2 + ε/2)`), and `k ∈ x^(9/2 + 10ε ± ε/100)` (`<= n^2 * x^(1/2 - ε)`).

- **Fourier Bracket Cancellation (`x/m + m` vs `x^(1/2 + 9ε)`):** Inside `ChTop` / `ChCore`, [SZ.T1..T4](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/SizeWindowBrackets/ChainSlopeWindows/LipschitzWeightAndMinimum.lean#L31) cancel all four terms of `errorBracketSizeWindows = nT * aE * (1 + m^2/k) + m * (2*n*m*b*x^ε + nT2*k*b*x^ε/(n^2*x^(-ε)))` upon dividing by `(nT * m * b * (nT2/n)/2)` at `Y = x^(1/2 + 13ε/8)`:
  1. `SZ.T1`: `nT * aE <= 2 * Y * (nT * m * b)` via `aE <= 2*x*b` and `x/m <= Y` (`m ≈ √x`);
  2. `SZ.T2`: `nT * aE * (m^2/k) <= 2 * Y * (nT * m * b)` via `x * m <= k => m^2/k <= m/x`;
  3. `SZ.T3`: `m * (2*n*m*b*x^ε) <= 4 * Y * (nT * m * b)` via `m <= x^(1/2 + ε/2)` and `n <= 2 * nT * x^(ε/8)` (`1/2 + ε/2 + ε + ε/8 = 1/2 + 13ε/8`);
