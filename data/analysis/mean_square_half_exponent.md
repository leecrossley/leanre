## 1. How `meanSqK` Proves the $O(y \log y \, \lvert P\rvert)$ Variance Bound `[L][M]`

- **Dead interface vs. live theorem `[L]`**: [MeanSquareHypW](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MeanSquareHypWIff.lean#L13) (cutoff $x^{400}$, $a_0 \equiv 3 \pmod 4$, multiplicative $\kappa$) is dead code not referenced in the live kernel graph. The live theorem is [QH.meanSqK](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/meanSqK.lean#L51) (`201` decls in `dom`, `1,565` project cone decls), which establishes [MeanSq](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/PrimeSetTwoBounds.lean#L26) for $S(Z,y,q,\kappa) = \sum_{1 \le n \le Z} c_N(y,n)\,\kappa(n)\,(\tfrac{n}{q})$ at $Z = (Y^K)^{400}$, $y \in [Y, Y^K]$, [cN](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/SecondEstimateOfIntervalHypothesis.lean#L23) $(y,n) = \Lambda(n)\min(1, y/n)$, and **any** $\kappa : \mathbb{N} \to \mathbb{C}$ with $\|\kappa(n)\| \le 1$ over $q \in$ [PPset](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/SecondEstimateOfIntervalHypothesis.lean#L50) $(m_0, a_0, U)$ (primes $q \in (U^{1/2}, U]$, $q \equiv a_0 \pmod{m_0}$, $8 \mid m_0$).
- **Not large sieve / Parseval / theta `[L][M]`**: Neither Montgomery–Vaughan, orthogonality of Dirichlet characters mod $q$, nor finite-field/theta second moments are used. `QH.meanSqK` proves variance directly via **prime-power expansion + quadratic reciprocity + PNT in arithmetic progressions with at most one Landau–Page exception**:
  1. *Diagonal/off-diagonal expansion*: [meansq_expand](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqMainA.lean#L9) expands $\|S\|^2$ and swaps $\sum_{q \in P}$ inside $\sum_{n,n' \le \lfloor Z\rfloor}$ using $\|\kappa(n)\| \le 1$. Because $8 \mid m_0$, $(a_0, m_0)=1$, and $q > U^{1/2} \ge Z^2 \ge n n'$, [abs_pair_sum_eq](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqMain.lean#L38) converts $|\sum_{q \in P} (\frac{n}{q})(\frac{n'}{q})|$ by quadratic reciprocity into $|\sum_{q \in P} (\frac{q}{s})|$ with $s =$ [soutPart](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MeanSquareHypWIff.lean#L48) $(m_0, n n')$ (odd squarefree part coprime to $m_0$).
  2. *Three-part split ([meanSq_abs](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/MeanSqAbs.lean#L8), [meansq_split](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqMainB.lean#L9))*:
     - $s = 1$ (same-prime powers + square/bad-prime `RR` terms) $\le \sum_p s_P(p)^2 + \mathrm{RR}^2$ ([pairs_one](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqPairs.lean#L255));
     - $s = \max(n^\star, 2)$ (single exceptional modulus) $\le 2B^2 + 2B\,\mathrm{RR}$ ([pairs_r](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqPairs.lean#L307), $B = 3\log y$ via [exists_primePowerSum_le_mul_log](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/SumMinLeDiv.lean#L71));
     - $1 < s \le \lfloor Z\rfloor^2$, $s \neq n^\star$: [twistK](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/twistK.lean#L148) gives $|\sum_{q \in P} (\frac{q}{s})| \le Y^{-(K+1)}\lvert P\rvert$ by combining [zFRDirichlet](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/LandauZeroFreeBounds/NoZeroComplex.lean#L32), [page_across](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqPage.lean#L37) + [jacobi_separate](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqOrth.lean#L133) (at most one exceptional $n^\star$), [pnt_progressions_relative_weak_holds](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/PNTFinal.lean#L22) + [twist_one](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqTwistB.lean#L221) (residue-class cancellation), and [count_a](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/MSqCount.lean#L346) ($\lvert P\rvert \ge U^{9/10}$).
  3. *Variance sum*: [sPsq_le](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/SPsqLe.lean#L161) ($\le C_3 y\log y$), [RR_le](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/RRLe.lean#L9) ($\mathrm{RR} \le 5C_1\sqrt{y}$ via $w = Y^{\varepsilon/5} \le y^{1/5}$), and [sum_cN_le](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/MeanSquareBounds/SumCNLe.lean#L8) ($Y^{-(K+1)}(\sum c_N)^2 \le C_4^2 y\log y$ via $(400K\log Y)^2 \le Y$ and $yY \cdot Y^{-(K+1)} \le 1$) yield total constant $C = C_3 + 25C_1^2 + 4C_2^2 + 20C_1C_2 + C_4^2$.
