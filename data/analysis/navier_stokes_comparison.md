## Executive Summary

1. **Unforced & conditional vs. forced & unconditional:** `tristanbuckmaster/navier-stokes` formalizes the **unforced** 3D incompressible Navier–Stokes equations (and a fractional dissipation variant with $1 < \alpha < 5/4$, unused by the paper), proving blow-up on $\mathbb{R}^3$ and $\mathbb{T}^3$ **conditionally** on the existence of a discretely self-similar profile or an abstract certificate / cell-layer system whose concrete 128-bit Arb/FLINT numerical witness is **external** and absent from the repository ([README.md](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/README.md#L34-L39)). By contrast, `openai/NavierStokesAndEuler` formalizes **unconditional** finite-time blow-up for **forced** 3D Navier–Stokes (Clay Millennium alternatives **(C)** and **(D)**, adapted from `formal-conjectures`) AND **unforced** 3D Euler blow-up on $\mathbb{R}^3$ ([formalization.yaml](https://github.com/openai/NavierStokesAndEuler/blob/f9e8bc5b38b6e212696e8a30e3e91517af887bbd/formalization.yaml#L6-L95)).
2. **All `sorry`s are Comparator/challenge stubs, not hidden library holes:** `navier-stokes` has **`24` `sorry` hits across `10` top-level statement files** (`17` core NS challenge stubs, `3` exact duplicates in the `7,086`-line reading bundle `CellLayerChallenge.lean`, and `4` unused fractional-dissipation stubs); all `24` have matching proved theorems in `Solution.lean` (`27` theorems total) and `0` `sorry`s appear inside `Breakdown/` (`2,259` files). `NavierStokesAndEuler` has **`4` `sorry` hits across `2` files**, all in `ComparatorChallenges/` (`2` Euler, `2` Navier–Stokes), with `0` `sorry`s across all `2,657` solution/library modules.
3. **Zero TCB escape hatches in source:** Both repos contain **`0` custom `axiom` declarations**, **`0` `native_decide`**, **`0` `decide +kernel`**, **`0` `unsafe`**, **`0` `@[implemented_by]`/`extern`**, **`0` `opaque`**, **`0` `Lean.ofReduceBool`/`Lean.trustCompiler`**, and **`0` `: True` / `PUnit` / 0-field structure stubs**. Note, however, that all six `comparator*.json` configs in `navier-stokes` set `"enable_nanoda": false`, whereas both `ComparatorChallenges/*.json` configs in `NavierStokesAndEuler` set `"enable_nanoda": true`.
4. **Style & `leanre` tool forensics:** `navier-stokes` shares `riemann-hypothesis`'s **zero-comment style** (`0` comment-only lines, `0` doc-comment files across `616,060` lines) and `89` `set_option maxHeartbeats` overrides, whereas `NavierStokesAndEuler` has **`31,222` comment-only lines (`4.87%`)**, doc-comments in **`2,642 / 2,659` (`99.4%`)** files, and **`0` `set_option` overrides** — yet carries **`133` unreachable dead/refactored modules (`32,700` lines outside `ComparatorChallenges/`)** including `13` exact alpha-renamed file-clone pairs (`*NoOptions.lean`, `*Investigation.lean`, `Drift*`).

## 1. Main Theorem Statements & Physical Assumptions

### 1.1 `tristanbuckmaster/navier-stokes` (Unforced Navier–Stokes, Conditional on Profile / Certificate)

Top-level statement files pair with [`lean/Solution.lean`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Solution.lean#L17-L355) via six `comparator*.json` configs (`propext`, `Quot.sound`, `Classical.choice` only). In [`lean/Challenge.lean`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L26-L108):

- **PDE & forcing:** `IsSmoothSolution ν u₀ u p` ([Challenge.lean#L26-L33](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L26-L33)) models **unforced** Navier–Stokes ($f \equiv 0$): `deriv (fun τ => u τ x) t + advectionAt (u t) x = ν • sumSecondPartialsAt (u t) x - gradientAt (p t) x` for `t > 0`, with `ContDiffOn ℝ ∞` on `[0, ∞) × ℝ³` and `u 0 x = u₀ x`. Notice `deriv` (not `derivWithin`) is only asserted for `t > 0`.
- **Whole space (`BreakdownOnSpace`):** [Challenge.lean#L35-L39](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L35-L39) quantifies `∀ ν > 0`, constructing smooth, **compactly supported** (`HasCompactSupport u₀`), divergence-free $u_0 : \mathbb{R}^3 \to \mathbb{R}^3$ with no global `IsSmoothSolution` satisfying `∃ C, ∀ t ≥ 0, ∫⁻ x, ENNReal.ofReal (‖u t x‖ ^ 2) ≤ ENNReal.ofReal C`.
- **Torus (`BreakdownOnTorus`):** [Challenge.lean#L41-L45](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L41-L45) constructs smooth, 1-periodic, divergence-free $u_0$ with no global `IsSmoothSolution` whose velocity stays 1-periodic — **without assuming pressure $p$ is periodic** (handled internally via Galilean shift, per [lean/README.md#L48-L51](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/README.md#L48-L51)).
- **Conditional hypotheses:** Every breakdown theorem in `navier-stokes` is an implication (`P → BreakdownOnSpace/Torus`):
  - `breakdown_on_space` / `breakdown_on_torus` ([Challenge.lean#L101-L105](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L101-L105)) assume `PeriodicSimilarityProfileExists` ([Challenge.lean#L51-L61](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L51-L61)): nonzero smooth $(W,q)$, period $P > 0$, linear isometry $R \in O(3)$ with $W(s+P,y)=R\,W(s,R^{-1}y)$, decay $|\nabla^j W| \le C(1+|y|)^{-1-j}$ ($j \le 2$), $|\nabla q| \le C(1+|y|)^{-3}$.
  - `breakdown_on_space_of_weak` ([Challenge.lean#L107-L108](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Challenge.lean#L107-L108)) weakens this to `WeakPeriodicSimilarityProfileExists` ($L^6_y W$, $L^2_y \nabla W$, $L^2_{s,y} \nabla^2 W$, distributional self-similar equation).
  - `certificate_orbit` ([CertificateChallenge.lean#L219](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/CertificateChallenge.lean#L219)) and `extended_certificate_orbit` ([ExtendedCertificateChallenge.lean#L265](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/ExtendedCertificateChallenge.lean#L265)) derive `WeakPeriodicSimilarityProfileExists` from `CertificateHypothesis` / `ExtendedCertificateHypothesis`.
  - `breakdownOnSpace_of_cell_system_condition`, `breakdownOnTorus_of_cell_system_condition`, and their conjunction ([CellLayerTheorems.lean#L12-L29](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/CellLayerTheorems.lean#L12-L29); [Solution.lean#L338-L355](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Solution.lean#L338-L355)) derive `BreakdownOnSpace` and `BreakdownOnTorus` from `CellLayerSystem.CellSystemCondition D X R T Y N B` ([StatementDefs.lean#L6223](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/Breakdown/CertCell/StatementDefs.lean#L6223)).
  - **Paper vs. formal gaps noted in `lean/README.md`:** Unlike paper Theorem 1.1 ([paper PDF p. 3](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/paper/finite-time-blow-up-navier-stokes.pdf)), the formal statements omit the explicit blow-up rate $(T-t)^{-1/4}$ and convergence to $W$, and `extended_certificate_orbit` stops at a weak profile rather than proving smoothness (Koch–Nadirashvili–Seregin–Šverák / Chae–Wolf, Proposition 7.11) ([lean/README.md#L52-L83](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/README.md#L52-L83)).
  - **Fractional Navier–Stokes (unused by paper):** [`FractionalChallenge.lean`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/FractionalChallenge.lean#L74-L80) states conditional blow-up for $1 < \alpha < 5/4$, and [`FractionalCellSystemChallenge.lean`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/FractionalCellSystemChallenge.lean#L4445-L4449) specializes to $\alpha = 501/500$.

## 3. External Certificate Boundary (`navier-stokes`) vs. Self-Contained Proof (`NavierStokesAndEuler`)

In `tristanbuckmaster/navier-stokes`, the mathematical gap between the Lean library and an unconditional clay-style blow-up theorem is cleanly isolated at `CellLayerSystem.CellSystemCondition`:

1. **What lives in Lean:** Lean proves `CellLayerSystem.CellSystemCondition D X R T Y N B → BreakdownOnSpace ∧ BreakdownOnTorus` ([CellLayerTheorems.lean#L24-L29](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/CellLayerTheorems.lean#L24-L29)), discharging Section 7's fixed-point / contraction-on-a-box argument ([lean/README.md#L106-L109](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/README.md#L106-L109)) plus Appendix B's Proposition B.1 (`PieceMultiplierDensityWeakHolds`) and Proposition B.4 (`IsCellFormBound`) ([lean/README.md#L91-L97](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/README.md#L91-L97)).
2. **What is external (neither data nor verifier in repo):** Both [`README.md#L34-L39`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/README.md#L34-L39) and [`lean/README.md#L99-L101`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/lean/README.md#L99-L101) state explicitly that **the formalization contains no data**. The paper ([paper PDF pp. 1, 49–71](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/paper/finite-time-blow-up-navier-stokes.pdf)) describes a 19-fold azimuthally symmetric approximate profile ($\kappa = 19$, period $\bar{S} \approx 0.36$) found via floating-point Newton's method and verified against Appendix B's conditions using **128-bit interval arithmetic in Arb via FLINT**. Neither the certificate payload (SHA-256 `3f7a335b84b6c7631742cacc5343dfcd11cf72f5221ff79b2b9268790b4b22c5` in the paper) nor the C/FLINT/Arb verification code is present in the repository.
3. **Final-patch / build caveat:** [`README.md#L45-L49`](https://github.com/tristanbuckmaster/navier-stokes/blob/ad53419de079eb8f95f60313473374624a348546/README.md#L45-L49) notes that a Nov 20, 2026 patch was applied to the cell-layer statements and dependent proofs (changing one weight to $(|m|+\tfrac12)^2$, allowing a zero cell constant, and restricting model harmonics), and **the patched Lean package was not rebuilt when the repo was assembled**.
4. **Contrast with `NavierStokesAndEuler`:** `openai/NavierStokesAndEuler` has **zero external numerical boundary**; its [`formalization.yaml`](https://github.com/openai/NavierStokesAndEuler/blob/f9e8bc5b38b6e212696e8a30e3e91517af887bbd/formalization.yaml#L48-L127) declares `scope: "Full formalization of main results"`, `sorry_count: 0`, `review.status: "self-assessed"`, and documents AI-assisted synthesis (`automation.methods`).
